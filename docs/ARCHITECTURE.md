# Architecture

This file is maintained with the code. The chat-graph diagram below is generated
from the compiled LangGraph `StateGraph` by `uv run etheria graph-diagram`
(spec 1.2 criterion 3); dotted arrows are conditional edges. The design and the
reasons behind it are in `docs/superpowers/specs/2026-09-28-etheria-v2-design.md`.

## Processes

| Process | Command | Runs |
|---|---|---|
| `api` | `uv run etheria api` | FastAPI and the chat graph in-process (LangGraph, checkpoints in Postgres) |
| `worker` | `uv run etheria worker` | The Temporal worker: `IngestDocumentWorkflow` for every upload, and `MaintenanceWorkflow` on the daily `maintenance-daily` schedule, which the worker creates at start if it is missing |
| Infrastructure | `docker compose -f infra/docker-compose.yml up -d` | Postgres 16 + pgvector, Neo4j, Redis, the Temporal dev server |

The daily maintenance workflow keeps monthly partitions of `messages` and `audit_log` three months ahead, drops `audit_log` months older than 12 months, and deletes checkpoint threads idle for 7 days or whose conversation is gone. `uv run etheria maintain` runs the same jobs once. Details: `docs/SECURITY.md`.

## Evals

| Suite | Command | Measures | Report |
|---|---|---|---|
| Extraction | `uv run etheria eval --suite extraction` | Lab-row recall against fixture ground truth, grounding, PII masking, the injected report (real `deepseek-flash`) | `docs/evals/extraction.md` |
| Retrieval | `uv run etheria eval --suite retrieval` | Hit@k, Recall@k, Precision@k and MRR for dense, keyword, hybrid and hybrid + rerank search over one user's reports; relevance known by construction; no LLM | `docs/evals/retrieval.md` |
| Graph | `uv run etheria eval --suite graph` | The owner's 26 scenarios (the pass/fail criterion), 6 extras and 15 held-out injection attacks through the real graph: triage, tools, safety rules, expectations graded by `deepseek-v4-pro`, latency, and faithfulness (claims in each reply checked against the context `generate` was given) | `docs/evals/graph.md`, replies in `graph-replies.md` |
