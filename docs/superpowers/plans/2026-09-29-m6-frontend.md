## Tasks
1. **Backend `DELETE /user`** (TDD, integration). One transaction deletes the user row (every user table cascades from `users`), then the encrypted files and the checkpoint threads are removed, and `audit_log.user_ref` for the user is replaced by an HMAC of the user id (key: `DATA_ENCRYPTION_KEY`, domain-separated). An `erasure` audit row is written with the pseudonymised ref. 204; the refresh cookie is cleared.
2. **Copy + prune.** Copy, delete removed features (admin, profile, dev/token, forgot-password, sso-callback, feedback modal, TTS, dead ChatView tree), `middleware.ts` + `proxy.ts` (client-side guarding, spec 13.1), drop `@clerk/nextjs`, husky, commitlint, lint-staged.
3. **Auth.** `src/lib/auth.tsx`: `AuthProvider`, `useAuth` / `useUser` / `useClerk` / `useSession` with the surface the pages use; access token in memory; silent refresh on load; single-flight `/auth/refresh` (concurrent 401s share one call); axios and `streamChat` retry once after a refresh. Sign-in and sign-up pages rewritten on it in the existing styling.
4. **api.ts.** Remove cut functions (spec 13.2); download = authenticated blob fetch + save; history `name`; error messages from the `{"error": {...}}` shape.
5. **Wire the flow.** Dashboard nav -> history / documents; regenerate; account page (email, sign out, delete account); history rename; document download; voice and Clerk claims out of the marketing copy.
6. **Verify.** `tsc --noEmit`, `eslint`, `next build`; backend unit + integration; browser run of the whole criterion-2 flow against the real stack.
7. **Docs.** Spec (13, 10, decision log), CLAUDE.md, Build Guide, memory; commit on main and push.
